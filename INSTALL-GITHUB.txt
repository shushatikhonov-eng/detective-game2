УСТАНОВКА ПОЛНОЙ СБОРКИ

ВАЖНО: не удаляйте сам репозиторий GitHub. Удаление репозитория может изменить адрес сайта и потребовать повторной настройки Pages.

1. Скачайте ZIP и распакуйте его.
2. Откройте папку wallace_full_project.
3. Загрузите ВСЁ ЕЁ СОДЕРЖИМОЕ в корень существующего репозитория detective-game2. Не загружайте саму папку как вложенную директорию.
4. Если GitHub спросит о замене совпадающих файлов — подтверждайте замену.
5. Откройте js/firebase-config.js. В шаблоне сейчас стоит null. Вставьте туда конфигурацию Firebase Web App из вашего действующего файла/проекта.
6. Commit changes.
7. Дождитесь публикации GitHub Pages.
8. Откройте сайт на компьютере и пульт на iPhone. Используйте комнату WALLACE31.

Если хотите полностью очистить репозиторий перед загрузкой, сначала сохраните копию содержимого js/firebase-config.js. После загрузки новой сборки вставьте конфигурацию обратно.
