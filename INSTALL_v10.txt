CASE 031 — ОБНОВЛЕНИЕ v10

Эта сборка сделана непосредственно на основе переданного архива case031_full_fixed_v8(2).zip.

Что исправлено:
1. 20 индивидуальных нуарных SVG-иллюстраций для материалов e1–e20; больше нет старых схематичных карточек-заглушек.
2. Карточки материалов оформлены как архивное досье: крупный заголовок и описание слева, тематическое изображение справа, архивная строка внизу.
3. Финальный экран скрыт до завершения седьмой главы. Он показывается только после финального ответа и выбирает победный/проигрышный портрет по результату.
4. На карте все места остаются приглушёнными, а места текущей главы выделяются ярко-красным маркером.
5. Карта не перетаскивается и не масштабируется игроками.
6. Добавлены версии ?v=10 к CSS и JS для обхода старого кеша.

Установка:
- Распаковать содержимое архива в корень репозитория GitHub Pages с заменой файлов.
- НЕ заменять js/firebase-config.js: он сохранён без изменений.
- Дождаться публикации GitHub Pages.
- На телевизоре и телефоне открыть страницу заново. Если старый экран остался, сделать жёсткую перезагрузку страницы.

Пульт remote.html и remote.js сохранены; логика Firebase-конфигурации не менялась.

Проверка:
- node --check: js/app.js, js/remote.js, data/game.js — без синтаксических ошибок.
- Визуальную проверку в реальном браузере после публикации необходимо выполнить отдельно.
