CASE 031 — ОБНОВЛЕНИЕ v13 (СБОРКА ДЛЯ СТАРЫХ БРАУЗЕРОВ SAMSUNG TIZEN)

Основа: case031_v12 (единый дизайн + честная раскладка доски дела).
Цель: главный экран и весь игровой процесс гарантированно работают
в браузере телевизора Samsung (включая Tizen 2016–2018 гг.).

ЧТО БЫЛО НА ТВ
На телевизоре открывалась только шапка («ROOM: … · LOCAL MODE · таймер»),
а заставка не отображалась — виден пустой фон. Причина: браузер ТВ не
поддерживает часть современных правил CSS (display:grid, inset, clamp(),
CSS-переменные, 8-значные цвета) и молча отбрасывал их. Заставка
задавалась через display:grid — правило отбрасывалось, экран оставался
display:none. Кроме того, библиотека MQTT v5 написана на современном
JavaScript (стрелочные функции, «?.») и вообще не загружалась на ТВ —
из-за этого не работала синхронизация с пультом iPhone.

ЧТО ИСПРАВЛЕНО В v13

1. CSS переписан в режиме двойной раскладки: для каждого правила сначала
   объявляется совместимый вариант (flex, фиксированные размеры, rgba),
   затем современный (grid, clamp). Новый браузер берёт современный
   вариант — дизайн на компьютере НЕ изменился; старый браузер берёт
   совместимый — заставка, доска дела, досье и финал теперь видны на ТВ.
2. CSS-переменные заменены на прямые значения цветов; inset → четыре
   стороны; 4/8-значные hex → rgba; width:min(...) → width + max-width;
   перед каждым clamp() добавлен запасной размер.
3. mqtt.min.js заменён с v5 на v2.18.8 — чистый ES5, работает даже в
   браузерах 2016 года.
4. Firebase SDK переключён с 10.12.2 на 8.10.1 (последняя версия с
   поддержкой старых браузеров). На скриншоте 1920×1080 проверено:
   шапка показывает FIREBASE SYNC — синхронизация с пультом работает.
5. Локальные шрифты: добавлен woff-фолбэк (старые ТВ не читают woff2).
   Шрифты по-прежнему лежат в папке fonts/ — интернет Google Fonts не нужен.
6. Диагностика прямо на экране: если что-то падает, вместо пустого фона
   внизу появляется красная плашка с текстом ошибки и данными браузера —
   достаточно сфотографировать её на телефон.
7. В шапке справа появился чип версии «v13» — по нему видно, что ТВ
   загрузил именно новую сборку, а не кэш.

КАК УСТАНОВИТЬ (ваш репозиторий detective-game2)

1. Распаковать архив: файлы должны лечь в КОРЕНЬ репозитория
   (рядом с README.md), а не во вложенную папку. С заменой файлов.
2. js/firebase-config.js в сборке сохранён без изменений.
3. Commit → дождаться публикации GitHub Pages (1–2 минуты).
4. На ТВ: закрыть браузер, открыть заново и ввести адрес страницы.
   Если в шапке нет надписи «v13» — значит, ТВ показывает кэш:
   в браузере ТВ открыть меню → «Обновить» (или очистить данные
   браузера) и открыть адрес ещё раз.
5. На iPhone пульт открывать как раньше по QR-коду с заставки.

ПРОВЕРЕНО В БРАУЗЕРЕ (Chromium, 1920×1080 — режим ТВ):
- заставка: постер, заголовок целиком, QR-код, кнопка «НАЧАТЬ РАССЛЕДОВАНИЕ»;
- шапка: код комнаты, FIREBASE SYNC, таймер, чип v13;
- доска дела: 3 карточки улик без наложений, третья во всю ширину,
  вопрос и кнопка «ПОДТВЕРДИТЬ ОТВЕТ» видны без прокрутки;
- досье улики: двухколоночная раскладка, изображение справа;
- финальный экран: портрет, вердикт, счёт, кнопка возврата;
- пульт iPhone (390×844): материалы главы синхронизируются с экраном ТВ;
- ошибки JS в консоли браузера отсутствуют; node --check: app.js,
  remote.js, game.js, mqtt.min.js — без ошибок.

УПРАВЛЕНИЕ ПУЛЬТОМ ТВ (без изменений):
стрелки — навигация, OK — открыть/выбрать, Return — закрыть/назад,
цветные кнопки — заметки / дальше / карта / назад.

ЕСЛИ НА ТВ ВСЁ РАВНО ПУСТО
Сфотографируйте экран: теперь при любой ошибке на нём появится красная
плашка с описанием — пришлите фото, по нему будет видно точную причину.
