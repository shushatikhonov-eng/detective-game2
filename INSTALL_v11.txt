CASE 031 — ОБНОВЛЕНИЕ v11 (SAMSUNG TV EDITION)

Основа: case031_full_fixed_v10.zip. Все изменения сделаны поверх вашей сборки.

Что исправлено:
1. ГЛАВНОЕ: js/app.js и js/remote.js переписаны на чистый ES5. Старый код использовал
   синтаксис ES2020 (?. и ??), стрелочные функции и динамический import() Firebase SDK.
   Браузер Samsung TV (Tizen) падал на первой же строке — сценарий не загружался,
   кнопки не реагировали. Теперь код выполняется в любых браузерах Tizen.
2. Управление пультом Samsung: стрелки — навигация по карточкам/ответам/кнопкам,
   OK — открыть/выбрать/подтвердить, Return — закрыть окно, цветные кнопки:
   красная — заметки, зелёная — следующая глава, жёлтая — карта, синяя — назад.
   Выбранный элемент подсвечивается янтарной рамкой.
3. QR-код на заставке ТВ: сканируете камерой iPhone — пульт открывается с кодом
   комнаты. Комната генерируется случайно при каждой загрузке ТВ
   (можно задать фиксированную: index.html?room=WALLACE31).
4. Резервный канал: если Firebase недоступен, ТВ и пульт автоматически переходят
   на публичный MQTT-брокер. Библиотеки Leaflet/QRCode/MQTT лежат локально
   в js/vendor — внешние CDN больше не нужны.
5. Все 20 иллюстраций улик (case-e1…e20.jpg) заменены на сгенерированные
   фотографии в едином стиле нуара 1930–40-х годов. Постер сохранён,
   конвертирован в JPEG.
6. Мелочи: кнопка ИСТОЧНИКИ на панели ТВ, тосты подтверждений, защита окна карты
   от быстрого закрытия, публикация состояния в Firebase (пульт мгновенно видит
   ход игры).

Установка:
- Распаковать содержимое архива в корень репозитория GitHub Pages с заменой файлов.
- НЕ заменять js/firebase-config.js: в сборке он сохранён без изменений.
- Дождаться публикации GitHub Pages.
- На телевизоре и телефоне открыть страницу заново. Если старый экран остался,
  сделать жёсткую перезагрузку страницы (или подождать 10 минут кеш).

  js/remote.js, data/game.js — без ошибок.
