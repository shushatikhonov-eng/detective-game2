# ДЕЛО № 031 — «Последний ход»

Интерактивная линейная детективная игра для вечеринки: телевизор Samsung показывает расследование, iPhone работает как пульт. Семь глав, исторические материалы, интерактивные вопросы, карта Ливерпуля, заметки команды, три финальные версии и закрытый исторический итог.

## Важно об исторической достоверности

Дело Джулии Уоллес реально. 25 апреля 1931 года Уильям Герберт Уоллес был признан виновным и приговорён к смерти. 19 мая 1931 года Court of Criminal Appeal отменил приговор, постановив, что обвинение не доказало вину с необходимой определённостью. Суд **не установил личность другого убийцы**. Поэтому правильный финальный ответ игры — вариант C: доступные материалы не позволяют достоверно назвать убийцу. Это не авторская догадка, а вывод, соответствующий первичному апелляционному решению.

В игре разделены: (1) установленные обстоятельства, (2) полицейская версия/аргументы обвинения, (3) аргументы защиты и (4) итог суда. Тексты показаний в интерфейсе в основном являются пересказами, а не дословными цитатами. Прямой перевод судебного решения отмечен отдельно. Не используйте игру как юридическую или академическую публикацию без сверки с оригиналами.

```text
├── firebase-rules.json        # Правила Firebase Realtime Database
└── assets/images/             # Оригинальные SVG-иллюстрации интерфейса
```

## Размещение на GitHub Pages

1. Создайте репозиторий, например `wallace-detective`.
2. Загрузите **содержимое** этой папки в корень репозитория (файл должен называться именно `index.html`, не `index.http`).
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`, нажмите `Save`.
5. Через некоторое время GitHub покажет адрес вида `https://USERNAME.github.io/REPOSITORY/`.

## Подключение TV и iPhone

Для связи двух разных устройств нужен Firebase Realtime Database. В одиночном режиме сайт можно открыть без Firebase, но команды с iPhone на телевизор не синхронизируются между разными устройствами.

1. Создайте проект на https://console.firebase.google.com/.
2. Добавьте Web App и скопируйте конфигурацию SDK.
3. В Firebase включите **Authentication → Sign-in method → Anonymous**.
4. Создайте **Realtime Database** в европейском регионе.
5. В `js/firebase-config.js` замените `window.FIREBASE_CONFIG = null;` на объект конфигурации, который выдаёт Firebase. Пример структуры уже есть в файле.
6. В Realtime Database → Rules вставьте содержимое `firebase-rules.json` и опубликуйте правила.
7. Закоммитьте и отправьте изменения в GitHub. Дождитесь обновления Pages.
8. На телевизоре откройте `https://USERNAME.github.io/REPOSITORY/`.
9. На iPhone откройте `https://USERNAME.github.io/REPOSITORY/remote.html?room=WALLACE31`.
10. На обоих устройствах должен быть один и тот же код комнаты. На iPhone нажмите «Подключиться», затем «Начать игру».

**Безопасность:** анонимная авторизация плюс приведённые правила защищают от неавторизованных запросов, но не делают комнату приватной от посетителей самого сайта. Используйте непредсказуемый код комнаты, не размещайте в игре личные данные и не применяйте эти правила для чувствительной информации. Для коммерческого или закрытого запуска нужны отдельная серверная проверка комнаты и более строгие правила.

## Карта и внешние сервисы

Карта работает на Leaflet и тайлах OpenStreetMap, поэтому для карты требуется интернет. Точки — ориентировочные географические ориентиры, а не геодезическая реконструкция 1931 года. Условия использования тайлов OpenStreetMap: https://www.openstreetmap.org/copyright.

Шрифты загружаются из Google Fonts; если они недоступны, используются системные запасные шрифты.

## Изображения

`assets/images/` содержит оригинальные SVG-иллюстрации, созданные для интерфейса (обложка, карточки документов, телефон, трамвай, судебные бумаги и т. д.). Это **не** исторические фотографии и они не маркируются как архивные.

Исторические фотографии, план дома и материалы места преступления доступны у архива-исследовательского проекта: https://www.williamherbertwallace.com/gallery/crime-scene-photos/. Они открываются внешними ссылками из карточек и не копируются в репозиторий, поскольку права и условия повторного использования не подтверждены. Для публичного коммерческого распространения нужно отдельно получить разрешения правообладателей.

## Игровая механика

- Линейный порядок из 7 глав; нельзя перескочить вперёд.
- В каждой главе есть карточки улик и контрольный вопрос с тремя вариантами.
- Ответ фиксируется один раз, после пояснения команда переходит дальше.
- Первые шесть глав дают до 10 баллов каждая; финальный вердикт — 40 баллов.
- Итоговый вариант C соответствует выводу апелляционного суда: виновность Уоллеса не доказана с необходимой определённостью, другой убийца судом не установлен.
- Время игры ориентировочно 140 минут. Таймер — обратный отсчёт на экране; он не блокирует игру.
- Карта меняет фокус по главам; доказательства открываются в модальном окне.
- На iPhone можно вести заметки и отправлять ответы/команды.

## Проверка перед вечеринкой

- Откройте сайт на том телевизоре и iPhone, которые будут использоваться.
- Проверьте Wi-Fi и доступ к Firebase/OSM.
- Пройдите одну тестовую главу и убедитесь, что ответ с iPhone появляется на TV.
- Откройте карту и проверьте, что она не перекрывает интерфейс.
- Для TV используйте полноэкранный режим браузера. TV-интерфейс рассчитан на один экран без вертикальной прокрутки; длинные материалы открываются внутри модальных окон.
