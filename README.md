# ДЕЛО № 031 — ПОСЛЕДНИЙ ХОД

Интерактивная детективная игра по делу Джулии Уоллес (Ливерпуль, 1931). Телевизор показывает общую доску расследования; iPhone работает как пульт. Документы, фотографии и карта открываются на телевизоре поверх доски.

## Структура

- `index.html` — экран телевизора / компьютера.
- `remote.html` — пульт iPhone.
- `css/style.css` — оформление Film Noir.
- `data/game.js` — главы, материалы, вопросы и исторические источники.
- `js/app.js` — логика игрового экрана и Firebase-синхронизации.
- `js/remote.js` — логика пульта.
- `js/firebase-config.js` — конфигурация Firebase Web App.
- `firebase-rules.json` — правила Realtime Database.
- `assets/images/` — оригинальные стилизованные визуализации игры.

## Публикация на GitHub Pages

1. Загрузите **содержимое этой папки** в корень репозитория (не загружайте папку `wallace_full_project` целиком).
2. В GitHub откройте `js/firebase-config.js` и замените `window.FIREBASE_CONFIG = null;` на конфигурацию вашего Firebase Web App. Используйте существующую конфигурацию проекта Wallace Detective Web.
3. Проверьте, что в конфигурации есть `databaseURL`, например URL вашей Realtime Database в регионе `europe-west1`.
4. Убедитесь, что в Firebase Authentication включён Anonymous sign-in.
5. В Realtime Database → Rules опубликуйте правила из `firebase-rules.json`.
6. В Firebase Authentication → Settings → Authorized domains должен быть домен GitHub Pages: `shushatikhonov-eng.github.io`.
7. В Settings → Pages репозитория выберите публикацию из ветки `main`, папка `/ (root)`.

## Проверка

1. Откройте TV-адрес на компьютере или телевизоре.
2. Откройте remote-адрес на iPhone.
3. Дождитесь статуса подключения на обоих устройствах.
4. Нажмите «Начать игру» на iPhone.
5. Откройте документ в списке материалов пульта: на телевизоре должно появиться модальное окно поверх доски.
6. Нажмите «Закрыть окно на ТВ»: телевизор должен вернуться к доске.
7. Проверьте выбор ответа и переход к следующей главе.

## Безопасность Firebase

Текущие правила позволяют любому анонимно авторизованному клиенту читать и записывать данные в известной комнате. Для частной игровой сессии это удобно, но не подходит для публичного сервиса. Не размещайте в репозитории приватные ключи Service Account. Firebase Web App config предназначен для клиентского приложения.

## Историческая точность и визуализации

Иллюстрации являются авторскими художественными реконструкциями в эстетике Film Noir и не выдаются за исторические фотографии. Содержание игровых материалов следует отличать от интерпретаций и гипотез. Источники перечислены внутри игры.
