# ДЕЛО № 031 — ПОСЛЕДНИЙ ХОД (v11 · Samsung TV Edition)

Интерактивная детективная игра по делу Джулии Уоллес (Ливерпуль, 1931). Телевизор показывает общую доску расследования; iPhone работает как пульт. Документы, фотографии и карта открываются на телевизоре поверх доски. Все 20 материалов дела иллюстрированы авторскими фотографиями в стиле кино-нуар 1930–40-х годов.

## Что нового в v11

1. **Совместимость с Samsung TV (Tizen).** `js/app.js` и `js/remote.js` переписаны на чистый ES5: без стрелочных функций, `?.`, `??`, `async/await` и динамического `import()`. Код работает в браузерах Tizen 2017+ и старше, где современный синтаксис вызывал синтаксическую ошибку и «мёртвый» экран.
2. **Управление пультом Samsung.** Стрелки — перемещение по элементам (умная пространственная навигация), OK/Enter — открыть или выбрать, Return/Back — закрыть окно, цветные кнопки: красная — заметки, зелёная — следующая глава, жёлтая — карта, синяя — назад. Текущий элемент подсвечивается янтарной рамкой.
3. **QR-подключение пульта.** На заставке — QR-код с адресом пульта и кодом комнаты. Отсканируйте камерой iPhone — пульт откроется уже привязанным к комнате. Комната генерируется случайно при каждой загрузке ТВ (или задайте свою: `index.html?room=WALLACE31`).
4. **Резервный канал связи.** Firebase остаётся основным транспортом; при его недоступности включается публичный MQTT-брокер (emqx → hivemq → mosquitto). На одном устройстве работает и BroadcastChannel.
5. **Новые иллюстрации.** Все 20 карточек-улик (`case-e1…e20.jpg`) сгенерированы в едином нуарном стиле: контровой свет, дым, дождь, глубокие тени. Постер конвертирован в JPEG (вес репозитория снижен вдвое).
6. **Доработки.** Окно «Источники» на ТВ (кнопка в нижней панели), тосты подтверждений, окно карты больше не падает при быстром закрытии, состояние публикуется в Firebase (пульт видит ход игры сразу).

## Структура

- `index.html` — экран телевизора / компьютера.
- `remote.html` — пульт iPhone.
- `css/style.css` — оформление Film Noir.
- `css/vendor/leaflet.css`, `js/vendor/` — локальные библиотеки (Leaflet, QRCode, MQTT): страница не зависит от внешних CDN.
- `data/game.js` — главы, материалы, вопросы и исторические источники.
- `js/app.js` — логика игрового экрана, пульт Samsung, QR, синхронизация.
- `js/remote.js` — логика пульта.
- `js/firebase-config.js` — конфигурация Firebase Web App (не менялась).
- `firebase-rules.json` — правила Realtime Database.
- `assets/images/` — нуарные иллюстрации дела.

## Управление с пульта Samsung TV

| Кнопка | Действие |
| --- | --- |
| Стрелки | Перемещение по карточкам, ответам и кнопкам |
| OK / Enter | Открыть материал, выбрать ответ, подтвердить |
| Return / Back | Закрыть окно на экране |
| Красная (A) | Заметки следственной группы |
| Зелёная (B) | Следующая глава / показать итог |
| Жёлтая (C) | Карта расследования |
| Синяя (D) | Назад (закрыть окно) |

Подсказка «ПУЛЬТ ТВ: СТРЕЛКИ · OK · RETURN» видна в правом верхнем углу на широких экранах.

## Подключение iPhone-пульта

1. Включите игру на телевизоре — на заставке появится QR-код и код комнаты.
2. Наведите камеру iPhone на QR-код — откроется `remote.html?room=КОД`.
3. Нажмите «Подключиться» (статус станет «ПОДКЛЮЧЕНО»), затем «Начать игру».
4. Если QR-код сканировать неудобно — откройте адрес пульта вручную и введите код комнаты с экрана.

Каналы связи (в порядке приоритета): Firebase Realtime Database → публичный MQTT-брокер → BroadcastChannel (одно устройство). Статус показывается в шапке ТВ: `FIREBASE SYNC`, `MQTT RELAY` или `LOCAL MODE`.

## Публикация на GitHub Pages

1. Загрузите **содержимое этой папки** в корень репозитория (не вложенную папку). Файл `js/firebase-config.js` уже содержит рабочую конфигурацию — не заменяйте его заглушкой.
2. В Realtime Database → Rules опубликуйте правила из `firebase-rules.json`.
3. В Firebase Authentication включён Anonymous sign-in; в Authorized domains добавлен домен `shushatikhonov-eng.github.io`.
4. В Settings → Pages репозитория: ветка `main`, папка `/ (root)`.
5. После публикации откройте страницы заново; если старый экран остался — жёсткая перезагрузка.

## Безопасность Firebase

Текущие правила позволяют любому анонимно авторизованному клиенту читать и писать данные в известной комнате. Для частной игровой сессии это удобно, но не подходит для публичного сервиса. Не размещайте в репозитории приватные ключи Service Account. Firebase Web App config предназначен для клиентского приложения.

## Историческая точность и иллюстрации

Иллюстрации — авторские художественные реконструкции (сгенерированные изображения в эстетике Film Noir) и не выдаются за исторические фотографии. Содержание игровых материалов следует отличать от интерпретаций и гипотез. Источники перечислены внутри игры (кнопка «ИСТОЧНИКИ» на ТВ).
